# 英文阅读应用 — 设计文档

## 概述

一款面向中国大学生和高中生的网页端英文阅读工具，帮助用户阅读真实英文文章并提供智能词汇辅助。开源项目，部署在 Vercel，通过 Cloudflare 配置自定义域名。

## 技术栈

- **框架**: Next.js (App Router) — Vercel 原生支持，文章页面 SSG 预渲染
- **样式**: Tailwind CSS
- **内容**: Markdown 文件 + YAML frontmatter 管理内置文章
- **状态**: React Context + localStorage（用户数据：收藏、已认识单词）
- **词汇匹配**: 静态 JSON 对照表（四级/六级/考研词汇，约 8000 词）

## 页面结构

### 1. 侧边栏（左侧固定，可折叠）

- 顶部折叠/展开按钮
- 菜单项：
  - **开始学习** — 文章画廊（默认首页）
  - **导入文章** — 粘贴或上传自己的文章
  - **生词收藏夹** — 查看所有已收藏的词汇
  - **学习统计** — 后期占位，阅读天数、词汇量等

### 2. 文章画廊（首页）

- 圆角卡片网格布局，每张卡片展示：
  - 文章封面图（或渐变色占位）
  - 标题
  - 来源标签（如 BBC、VOA、The Guardian）
  - 难度标签（四级 / 六级 / 考研）
- 顶部筛选栏：按难度、来源、主题筛选
- 点击卡片 → 进入阅读页

### 3. 阅读页

三区布局：

```
┌───┬────────────────────────┬──────────┐
│ 侧│  ← 返回    高亮开关 ○◉  │ 词│句     │
│ 边│                        ├──────────┤
│ 栏│  文章正文               │ 🟢 单词  │
│   │                        │  [⭐][✓] │
│   │  hover 弹窗显示释义     │          │
│   │  和收藏按钮             │ 🔴 单词  │
│   │                        │  [⭐][✓] │
└───┴────────────────────────┴──────────┘
```

**顶栏**: 返回按钮 + 高亮开关 + 文章难度标签

**正文区（中间）**:
- Markdown 渲染
- 开关关闭：纯净阅读，无高亮
- 开关打开：生词底部显示色块
  - 绿色 = 四级
  - 黄色 = 六级
  - 红色 = 考研及以上
- 鼠标悬停高亮词 → 弹出释义卡片（中文释义 + 词性 + ⭐ 收藏按钮）

**右侧面板（占 1/6 宽度）**:
- 顶部两个标签切换按钮：**词汇** | **句子**（句子后期做）
- 词汇标签页：列出当前文章所有生词
- 每个词显示：难度色点 + 单词 + 简要释义 + ⭐ 收藏 + ✓ 已认识
- 点击 ✓ → 从本文生词列表中移除，并全局标记为已知（不再高亮）
- 点击 ⭐ → 加入全局收藏夹

### 4. 生词收藏夹页

- 查看所有已收藏词汇（跨文章汇总）
- 可按文章来源分组，或平铺列表 + 搜索过滤
- 支持导出 JSON/CSV（后期）
- 支持移除单个词汇

### 5. 导入文章页

- 文本框粘贴文章内容
- 可选：粘贴 URL 自动抓取内容（后期）
- 导入后自动分析词汇，进入阅读模式

## 数据流

### 词汇检测流程

```
文章正文 → 分词 → 对照词汇表查询
  → 跳过用户已标记"认识"的词
  → 剩余生词按难度分色
  → 渲染时高亮显示（开关打开时）
```

### localStorage 数据结构

```ts
{
  knownWords: string[],        // 用户标记为"认识"的单词
  savedWords: {                // 用户收藏的单词
    [word: string]: {
      date: string,
      articleTitle: string,
      difficulty: "cet4" | "cet6" | "postgrad"
    }
  },
  importedArticles: {          // 用户导入的文章
    [id: string]: {
      title: string,
      content: string,
      date: string
    }
  }
}
```

## 文章内容格式

### Markdown Frontmatter

```md
---
title: "科技趋势 2026"
source: "BBC News"
difficulty: "cet6"
topic: "technology"
coverImage: "/covers/tech-2026.jpg"
date: "2026-05-01"
---

文章正文内容...
```

文章存放在 `content/articles/` 目录，每篇一个 `.md` 文件。

## 开发阶段

### 第一阶段：核心阅读 MVP
- Next.js 项目初始化 + Tailwind
- 可折叠侧边栏布局
- 文章画廊（硬编码 3-5 篇文章）
- 阅读页 Markdown 渲染
- 词汇对照表（四级/六级）
- 高亮开关 + hover 弹窗
- 右侧生词面板（仅词汇标签）
- localStorage：已知单词 + 收藏单词

### 第二阶段：用户功能
- 导入文章（粘贴文本）
- 生词收藏夹页面
- 暗色/亮色模式切换
- 更多内置文章

### 第三阶段：高级功能
- 句子标签页（语法拆解）
- 文章搜索（API 对接）
- 导出词汇表
- 学习统计页
- 一次性访问密钥

## 设计备注

- **无登录系统** — 所有用户数据存浏览器 localStorage，通过导出备份
- **开源友好** — 文章为 Markdown 文件，方便通过 PR 贡献新文章
- **响应式设计** 但桌面端优先（学生主要在笔记本上阅读）
- **字体**: 正文用衬线体（阅读舒适），界面用无衬线体
- **配色**: 亮色模式下中性色调，具体色值实现阶段确定
